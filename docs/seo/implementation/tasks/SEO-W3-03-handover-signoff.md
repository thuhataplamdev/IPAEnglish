# SEO-W3-03 — Handover + Sign-off

**Timing:** Week 3 — Final  
**Owner:** SEO Exec + Dev / Tech Exec  
**Priority:** High  
**Dependencies:** SEO-W3-01, SEO-W3-02

## Objective

Đóng engagement bằng trạng thái minh bạch: những gì đã làm, bằng chứng, những gì accepted/deferred và cách theo dõi sau bàn giao.

## Required handover artifacts

1. Final `TECHNICAL-SEO-AUDIT.md`.
2. Final `KEYWORD-MAP.md`.
3. Initial/final Screaming Frog evidence references.
4. 4 target-page final Title/Description/H1/H2/ALT/current-copy status.
5. Technical fix status:
   - sitemap;
   - 404/301;
   - robots;
   - HTTPS;
   - image/WebP;
   - cache.
6. GSC property + sitemap status.
7. GA4 verification status.
8. Deferred/next-actions list.

## Sign-off checklist

- [ ] Initial crawl completed.
- [ ] Technical issues assigned and final status updated.
- [ ] Re-crawl completed.
- [ ] GSC and sitemap verified/submitted.
- [ ] GA4 verified.
- [ ] Keyword Map finalized.
- [ ] Four target URLs verified after on-page changes.
- [ ] Deferred items documented.
- [ ] No out-of-scope work silently included.
- [ ] No secrets/credentials in repo.

## Post-handover note

Search ranking/indexing may continue changing after delivery. Follow-up monitoring can compare GSC page/query metrics against the dated baseline, but ranking guarantees are not part of this task pack.

## Definition of Done

Gate C passes and all unresolved work has explicit owner/status or Change Request.
